## Notes from Class Personal Website

This is my personal site, designed to give a little background information on me while showing many of the notes I have taken for Software Systems 110 at Western Technical College. The site showcases my ability to use CSS and JavaScript to make a website ~~cause possible eyestrain~~ come to life.

**There are two major sections of the site:**

* About Me

    Contains information about myself.

* My Notebook

    Contains a gallery of photos of my handwritten notes from class, with functioning clickable buttons to advance forwards and back through the pages. A dialog box pops up once visitors have reached the last page, letting them know they are about to advance through the loop once more. This dialog box does not pop up if a visitor gets to the last page of notes by clicking "Previous Page" from Page 01 of the notes.
